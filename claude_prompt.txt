## Critical facts about Vencord system
- In .tsx regex literals, use \i (single backslash-i). Vencord processes the regex source text directly at build time and converts \i to an identifier matcher. NOT double backslash.
- $self in replace string becomes the plugin path at build time
- Vencord patches work on the module FACTORY source code, before the module executes
- The factory source might look DIFFERENT from the runtime source (different variable names in the function body)
